# Regels

## Rekenregels (packages/playbook, met tests)
- Maximale kost per verkoop = orderwaarde × marge. Lisa: 58 × 0,40 = **€23,20**.
- Break-even ROAS = 1 / marge. Lisa: 1 / 0,40 = **2,5**.
- ROAS = omzet / uitgegeven. Lisa: 638 / 280 = **2,28**.
- Kost per verkoop = uitgegeven / verkopen. Lisa: 280 / 11 = **€25,45**.
- Verliezer = uitgegeven ≥ 3 × doel zonder resultaat. Lisa A4: €72 ≥ €69,60 → verliezer. Tom B3: €60 ≥ 3 × €20 → verliezer.
- Winnaar: haalt het doel (ROAS ≥ break-even, of kost per aanvraag ≤ doel).
- Labels: Winnaar, Nog geen winnaar, Verliezer, Te vroeg om te zeggen, Enkel rapportage (doel zonder verkoop).
- Leads-maximum = klantwaarde × marge × slaagkans.
- Minimum budget €10/dag, webshop €30/dag.
- Schalen: [schaalstappen PJ] (prototype +20%). Nieuwe ad set elke [x weken, PJ] (prototype 2). Funnel [standaardverdeling PJ] (prototype 2 top, 2 middle, 1 bottom).

- Extra's van Meta (Advantage+ creative) standaard uit; aanzetten = waarschuwing.
